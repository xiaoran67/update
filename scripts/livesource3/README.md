# 🎬 直播源处理系统

一个高效、稳定的直播源处理系统，支持多源采集、智能分类、去重优化和多种输出格式。

## ✨ 核心特性

```text
- 🔄 多源采集 - 支持从多个URL源自动获取直播源
- 🏷️ 智能分类 - 基于字典的自动频道分类
- 🚀 高效去重 - 使用Set哈希算法，10万频道秒级处理
- 📁 多格式输出 - 支持TXT和M3U格式
- ⚡ 性能优化 - 专为大规模频道处理设计
- 🛡️ 稳定可靠 - 完善的错误处理和重试机制
```

📦 输出文件

```text
| 文件类型 | 描述 | 适用场景 |
|---------|------|----------|
| full.txt/m3u | 完整版源文件 | 包含所有分类的完整频道列表 |
| simple.txt/m3u | 精简版源文件 | 只包含主要频道的精简版本 |
| custom.txt/m3u | 定制版源文件 | 根据需求定制的频道组合 |
| others.txt | 补充源文件 | 未分类的补充频道源 |
```

⚙️ 核心功能

智能分类系统

```text
系统按照优先级进行频道分发：

1. 央视频道 (CCTV系列)
2. 卫视频道 (省级卫视)
3. 体育赛事 (体育直播)
4. 地方频道 (湖北、广东等)
5. 其他分类 (电影、电视剧、音乐等)
6. 其他源 (未分类频道)
```

高效去重机制

```text
- Set哈希去重 - 使用MD5哈希值进行高效去重
- URL标准化 - 自动清理URL参数，统一格式
- 多级去重 - 处理过程中和最终输出都进行去重
```

频道名称处理

```text
- 繁简转换 - 自动转换繁体频道名称
- 名称清理 - 移除多余标识（如"高清"、"HD"等）
- 格式统一 - 标准化CCTV和卫视频道名称
```

多源支持

```text
- URL源 - 支持HTTP/HTTPS直播源
- M3U格式 - 自动识别和转换M3U格式
- 日期变量 - 支持动态日期URL（如{MMdd}）
```

🔧 高级配置

黑名单管理

```text
在 blacklist/ 目录下维护黑名单：

- blacklist_auto.txt - 自动生成的无效源
- blacklist_manual.txt - 手动添加的无效源
```

白名单优化

```text
系统会自动从白名单中提取响应时间<2秒的高速源。
```

手工区定制

```text
在 手工区/ 目录下添加自定义频道，系统会：

- 自动合并到对应分类
- 进行去重检查
- 保持原始频道名称
```
